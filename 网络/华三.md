
## 端口镜像

根据镜像源与镜像目的是否位于同一台设备上，可以将端口镜像分为：
- 本地端口镜像（SPAN-Switch port Analyzer）
- 远程端口镜像（RSPAN，Remote SPAN）




### 本地端口镜像 (SPAN)

![[Pasted image 20260813112152.png|658]]

```bash
[Device]
mirroring-group 1 local
mirroring-group 1 mirroring-port ten 3/0/1 ten 3/0/2 both
mirroring-group 1 monitor-port ten 3/0/3

# 目的端口需要关闭生成树协议
interface ten 3/0/3
	undo stp enable
	
display mirroring-group all
Mirroring group 1
	Type: Local
	Status: Active
	Mirroring port:
		Ten-GigabitEthernet3/0/1  Both
        Ten-GigabitEthernet3/0/2  Both
    Monitor port: Ten-GigabitEthernet3/0/3

```



 
### 二层远程端口镜像
![[Pasted image 20260813112743.png]]
```zsh
[DeviceA]
vlan 2
	undo mac-address mac-learning enable 
	quit

mirroring-group 1 remote-source
mirroring-group 1 remote-probe vlan 2
mirroring-group 1 mirroring-port ten 3/0/1 both
mirroring-group 1 monitor-egress ten 3/0/2
# 配置镜像出接口为trunk口，关闭生成树协议
int ten 3/0/2
	port link-type trunk
	port trunk permit vlan 2
	undo stp enable

# DeviceB 中同样配置用于镜像的vlan和trunk口，关闭trunk口的stp
...

[DeviceC]
int ten 3/0/1
	port link-type trunk
	port trunk permit vlan 2
	
vlan 2
	undo mac-address mac-learning enable
	
mirroring-group 2 remote-destination
mirroring-group 2 remote-probe vlan 2
mirroring-group 2 monitor-port int ten 3/0/2

```



### 三层远程端口镜像（ERSPAN）
ERSPAN技术实现的功能是将镜像报文封装为协议号是0x88BE的GRE报文，路由到远端监控设备。

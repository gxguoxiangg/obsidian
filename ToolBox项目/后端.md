
## 技术栈

| **FastAPI**                             | 处理 HTTP 请求、定义接口、自动生成 Swagger 文档        | 前台接待员                 |
| --------------------------------------- | -------------------------------------- | --------------------- |
| **uvicorn**                             | 把 FastAPI 程序"跑起来"的服务器进程                | 餐厅的电闸（不拉闸灯不亮）         |
| **SQLAlchemy 2.0**                      | 用 Python 代码操作数据库（ORM）                  | 翻译官（Python 话 → SQL 话） |
| **asyncpg**                             | 连接 PostgreSQL 数据库的驱动                   | 电话线                   |
| **PostgreSQL**                          | 真正存数据的数据库                              | 仓库                    |
| **Alembic**                             | 管理数据库表结构"版本"，可以升级/回滚                   | 装修记录册                 |
| **Pydantic v2**                         | 定义数据的"形状"，自动校验对错                       | 质检员                   |
| **pwdlib / PyJWT**                      | 密码哈希、签发登录令牌（JWT）                       | 保险柜和入场券               |
| **python-frontmatter / markdown-it-py** | 解析 Markdown 的 front matter 和正文、渲染 HTML | 翻译 Markdown 的工人       |

## 工作流程

1. 发出请求
2. 服务器接收（uvicorn）
3. 路由匹配（FastAPI）
4. 参数准备（FastAPI + Pydantic）
5. 执行函数（业务逻辑）
6. 查询数据库（SQLAlchemy + asyncpg + PostgreSQL）
7. 组装相应（Pydantic校验 + 序列化）



## 代码结构导览

项目根目录的 `app/` 是核心代码。

```
backend/
├── app/                          ← 核心代码都在这里
│   ├── main.py                   ★ 应用入口：创建 FastAPI、挂路由、CORS、启动初始化
│   ├── core/                     「基础设施层」：谁都能用的公共东西
│   │   ├── config.py             配置（读 .env 环境变量）
│   │   ├── security.py           密码哈希 + JWT 签发/校验
│   │   └── deps.py               依赖注入（当前用户解析）
│   ├── db/                       「数据库层」：引擎、会话、基类
│   │   ├── base.py               ORM 基类（所有表从这里继承）
│   │   ├── session.py            数据库连接池、get_db 依赖
│   │   └── init_db.py            dev 环境自动建管理员
│   ├── models/                   「ORM 层」：每张表一个 Python 类
│   │   ├── user.py               用户表
│   │   ├── article.py            文章表
│   │   ├── item.py               条目表（核心！一个 H2+五个H3）
│   │   ├── image.py              图片表
│   │   ├── code_block.py         代码块表
│   │   ├── keyword.py            关键词表
│   │   └── push_event.py         推送审计表
│   ├── schemas/                  「契约层」：Pydantic 模型，定义请求/响应形状
│   │   ├── article.py            文章的输入/输出模型
│   │   ├── item.py               条目的输出模型
│   │   ├── auth.py               登录相关模型
│   │   ├── push.py               推送的输入模型（也是解析器的产出物！）
│   │   └── common.py             分页包装
│   ├── services/                 「业务层」：真正的逻辑，CLI 和 API 共用
│   │   ├── markdown_parser.py    ★ 解析 Markdown → 结构化数据
│   │   ├── article_service.py    ★ 文章入库（幂等 upsert）
│   │   ├── item_service.py       条目构建/更新
│   │   └── auth_service.py       用户查询/创建/认证
│   └── api/v1/                   「路由层」：HTTP 相关，只做"翻译"
│       ├── router.py             汇总所有接口
│       └── endpoints/            每个功能一组接口
│           ├── auth.py           登录 / 当前用户
│           ├── articles.py       读文章
│           ├── items.py          读条目
│           └── push.py           推送数据
├── scripts/                      ★ 命令行工具（不通过 HTTP，直接跑）
│   ├── ingest_markdown.py        把 Markdown 文件解析入库
│   └── create_user.py            创建用户
├── alembic/                      数据库迁移脚本
├── tests/                        pytest 测试
├── Dockerfile / docker-compose.yml   容器化部署
└── README.md                     项目简介
```
